## Loom preview

A Roblox UI scene, rendered live by loom inside these docs. The URL goes
through `loomPreviewUrl`, not a literal string: a raw `src` never passes
through Next's router, so it would keep pointing at the domain root once the
site is deployed under a `basePath`.

import { loomPreviewUrl } from '@/lib/site-config';

<iframe
  src={loomPreviewUrl('src/targets/CardScene.loom.tsx')}
  style={{ width: '100%', height: 360, border: '1px solid #333', borderRadius: 8 }}
/>
